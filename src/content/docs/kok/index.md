kok 是一个本地优先的工作台。你可以读、看、听电脑里的资料，做一份文档或演示，也可以请 Agent 根据选定的资料协助创作。

[入门](#由此开始) · [Agent](#agent) · [我的作品](#我的作品) · [资料库](#资料库) · [设置](#设置) · [常见问题](/docs/kok/reference/faq/)

这份帮助适用于 **v0.11.2 Preview**。下载、系统要求和更新方式见[安装 kok](/docs/kok/getting-started/install/)。


## 由此开始

1. [下载并运行 kok](/docs/kok/getting-started/install/)。
2. [读一份资料，写下第一篇笔记](/docs/kok/getting-started/first-work/)。可以使用随包附带的示例，无需配置 AI。
3. [用资料做一份报告和 PPT](/docs/kok/getting-started/first-agent-project/)。这条教程会带你配置 AI、检查来源、确认修改、继续改稿和导出。

## 三个工作区域

- **Agent** 帮你查找资料、整理内容和提出改稿方案。[认识 Agent](/docs/kok/agent/)
- **我的作品** 用来新建或继续编辑，相关的资料、要求和成果可以放进同一个创作项目。[认识我的作品](/docs/kok/works/)
- **资料库** 用来播放、阅读、收藏和查找本地文件。[认识资料库](/docs/kok/library/)

## 按任务查找

| 你想做什么 | 操作说明 |
| --- | --- |
| 新建 PPT、双击改字或拖动换页 | [制作与编辑演示文稿](/docs/kok/works/presentations/) |
| 改报告中的一段，或找回旧稿 | [编辑、对比与恢复文档](/docs/kok/works/create-documents/) |
| 过几天继续做同一件作品 | [继续创作项目](/docs/kok/works/continue-editing/) |
| 查找较早的项目和导出的副本 | [项目搜索与交付记录](/docs/kok/works/continue-editing/#项目搜索与交付记录) |
| 核对 Agent 的来源和修改 | [审查与撤销修改](/docs/kok/agent/review-changes/) |
| Agent 停在一半或提示回答未完成 | [找回结果与继续任务](/docs/kok/agent/results-history/) |
| 找回看到一半的视频或书 | [继续、收藏与最近打开](/docs/kok/library/continue-favorites/) |
| 换电脑或升级，保留资料和笔记 | [数据、备份与更新](/docs/kok/settings/data-backup/) |
