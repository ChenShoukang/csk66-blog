kok 是一个**本地优先**的媒体与知识仓库：把视频、照片、音乐、文档和电子书收进同一个资料库，用「空间」组织主题，用摘录把原文和笔记连起来，需要时再让 AI 帮忙翻译、整理和写作。

## v0.9.5 更新

- **紧凑侧栏**：≤820px 时只保留今天、Agent、全部文件、空间和「更多」，加上底部设置；图标 18→20px，点击目标 36→40px，650×520 小窗口下不再需要滚动。文件类型筛选留在资料库工具栏，避免和侧栏重复。
- **「更多」浮层**：从顶栏下方展开，只显示目的地名称和分隔线；私密文件夹、收藏、最近打开、配方、回顾、知识图谱、新建分类仍可达，当前隐藏入口让「更多」保持活动态。
- **字体与焦点**：图标提示 11→12px，搜索模式、侧栏分组标题与计数 11→12px；菜单首项去掉外框只保留行高亮，补充 `aria-haspopup`。
- **动效**：面板在打开动画中途关闭时保留当前 transform、不再跳变；导航指示条只动画 transform / opacity，时长 500→240ms，减少动效模式下禁用相关 transition。

## 最近几版（0.9.3 – 0.9.4）

- **扁平界面改版（0.9.4）**：统一视觉语言、分组导航、文件卡片 / 列表、阅读与媒体工具栏、空状态；深浅主题与中英文逐页复核；键盘文件导航、锚定菜单、焦点恢复、减少动效偏好，内置 Lucide 离线图标子集。
- **本地 MCP 沙箱（0.9.3）**：每个 stdio 服务可指定可写便携运行时目录并启用 AppContainer，主程序只授予只读执行 ACL，不可授权目录明确拒绝。
- **MCP OAuth 设备码（0.9.3）**：支持 user code / 验证地址、authorization_pending、slow_down、过期与拒绝处理，令牌 DPAPI 加密并支持 refresh。
- **PDF / 视频批量索引（0.9.3）**：审批后执行 `index_pdf_pages`（PDFium 文本层，≤25 页）与 `index_video_frames`（FFmpeg + Windows OCR，≤12 帧），合并进本地内容索引。

## 能做什么

- **收集与整理**：拖入文件或文件夹，按类型浏览、分类、收藏和检索；同一主题的资料可以放进同一个空间。
- **阅读与记录**：接着上次的位置看、听、读；划线、高亮、写想法，把段落、时间点或照片区域保存成带来源的摘录。
- **关联与创作**：用 `[[双向链接]]` 连起笔记，在图谱里查看关系；摘录可以加入笔记、空间或 PPT，继续编辑和导出。
- **按需交给 AI**：围绕当前资料提问、翻译或对比；也可以给 Agent 一个任务，先看它读了哪些来源、要改什么，再决定是否执行。

## 一些细节

- Windows 10 / 11 x64 桌面应用，界面跑在 WebView2 里，开发时用 Node.js 和 PowerShell 构建。
- 索引、笔记和历史存在本地 SQLite；收录不搬动原件，移除记录也不会删除原文件。
- 纯净模式可以完全离线使用；智能模式才启用 AI 能力，也可以接 DeepSeek、Ollama、LM Studio 等兼容接口。
