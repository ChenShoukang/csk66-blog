kok 是一个**本地优先**的媒体与知识仓库：把视频、照片、音乐、文档和电子书收进同一个资料库，用「空间」组织主题，用摘录把原文和笔记连起来，需要时再让 AI 帮忙翻译、整理和写作。

## v0.9.8 更新

- **界面改版**：统一偏白浅色与微紫深色主题，移除欢迎页宣传段落和重复入口；所有宽度保留短侧栏，文件类型归到资料库工具栏；「更多」改为三列图标面板，图标换成离线 Phosphor 双层填充。
- **Agent 聚焦**：首屏只保留资料、要求、按资料给出的建议操作和发送 / 停止；技能、用量档位、调用协议收进默认折叠的「高级设置」，选中资料后范围自动按所选执行。
- **本地只读计划 `agentLocalPlan`**：统计、列表筛选、分类概览、标签概览、文件类型分布等显式只读请求由本地规则直接回答——零模型请求、零网络、零写入，未配置 API 密钥也能用。
- **检索片段化**：同一份长文件最多返回 3 个带页码 / 章节 / 字幕时间锚点的片段，`read_items` 返回每份来源的读取覆盖；工具调用消息改为稳定前缀 + 动态尾部；任务结束给出成果卡片。
- **评测**：30 项固定任务前后对比，请求 100 → 76（−24%）、输入 token 566,586 → 431,132（−24%），节省主要来自本地任务分流；608 项原生检查通过。

## 最近几版（0.9.3 – 0.9.5）

- **紧凑侧栏（0.9.5）**：≤820px 只保留今天 / Agent / 全部文件 / 空间 / 「更多」+ 设置，图标 18→20px、点击目标 36→40px，小窗口不用滚动；面板动画、焦点与 `aria-haspopup` 一并调整。
- **扁平界面（0.9.4）**：统一视觉语言与分组导航、键盘文件导航、锚定菜单与焦点恢复、离线图标子集。
- **本地 MCP 沙箱（0.9.3）**：stdio 服务可指定可写便携运行时目录并启用 AppContainer，主程序只授予只读执行 ACL。
- **MCP OAuth 设备码（0.9.3）** 与 **PDF / 视频批量索引（0.9.3）**：审批后执行 `index_pdf_pages` / `index_video_frames`，合并进本地内容索引。

## 能做什么

- **收集与整理**：拖入文件或文件夹，按类型浏览、分类、收藏和检索；同一主题的资料可以放进同一个空间。
- **阅读与记录**：接着上次的位置看、听、读；划线、高亮、写想法，把段落、时间点或照片区域保存成带来源的摘录。
- **关联与创作**：用 `[[双向链接]]` 连起笔记，在图谱里查看关系；摘录可以加入笔记、空间或 PPT，继续编辑和导出。
- **按需交给 AI**：围绕当前资料提问、翻译或对比；也可以给 Agent 一个任务，先看它读了哪些来源、要改什么，再决定是否执行。

## 一些细节

- Windows 10 / 11 x64 桌面应用，界面跑在 WebView2 里，开发时用 Node.js 和 PowerShell 构建。
- 索引、笔记和历史存在本地 SQLite；收录不搬动原件，移除记录也不会删除原文件。
- 纯净模式可以完全离线使用；智能模式才启用 AI 能力，也可以接 DeepSeek、Ollama、LM Studio 等兼容接口。
