kok 是一个**本地优先的个人 AI Agent 工作台**：把视频、照片、音乐、文档和电子书收进本机资料库，
需要时交给 Agent 整理、阅读、写作和制作可继续编辑的成果；不需要 AI 时，也可以只把它当作播放器、
阅读器和资料管理器使用。

> **完整介绍与操作手册：[kok 帮助中心](/docs/kok/)**

## v0.11.2 更新

- **「用示例试一次」**：空白的 Agent 首页和「我的作品」都能一键开始——阅读示例、写下想法，在本机生成一篇可继续修改的 Markdown 笔记，全程不联网。
- **「全部项目」搜索**：可按名称或目标查找较早的项目，也可以把手动创建的托管文档或 PPT 加入项目成果。
- **项目交付记录**：显示成功导出的副本、时间、位置和文件指纹，可以在文件夹中定位；取消导出不记入交付记录。
- **中文帮助中心**：新增两条入门教程，更新 PPT 编辑、历史版本和回答恢复说明。

## 最近几版（0.10 – 0.11）

- **v0.11.1 · PPT 制作**：接入明确授权的视觉指引（Apache 2.0，固定上游提交），默认杂志风格、四套主题、九种原生可编辑构图；双击文字直接修改并自动保存；输出超限时按原请求分段继续。
- **v0.10.13 / 0.10.12 · 创作项目**：完整验收（资料 → 报告 → 改稿 → 选段交给 Agent → 八页 PPT → 重启续作 → 命名版本恢复 → DOCX / PPTX 导出），历史版本检查点与恢复。
- **v0.10.10 · 项目实体**：把「空间」扩展成项目（目标、风格 / 验收要求、状态、资料、成果、相关会话），可以从项目随时继续创作。
- **v0.10.9 · Codemode / RPC**：沙箱内可组合只读资料库工具；`kok-agent.exe --rpc` 提供 Headless RPC，方便编辑器和 CI 驱动。
- **v0.10.x 前期**：文档版本差异预览与恢复、局部改稿（选段 / 当前页交给 Agent）、PPT 版本与编辑能力补齐。

## 能做什么

- **欣赏**：视频续播、倍速、全屏与外挂字幕；音乐专辑、队列与后台播放；照片浏览与编辑；EPUB / PDF / TXT 阅读与书签。
- **整理**：分类、收藏、最近打开、搜索、智能集合、回顾、知识图谱与空间（网格 / 画布 / 时间线 / 图谱）。
- **创作**：新建文档与演示文稿；剪辑已有音视频、整理 PDF 页面；导出成品回到资料库，用同一套播放器和阅读器欣赏。
- **协作**：Agent 在选定范围内检索、阅读、整理、写笔记、创建文档；修改先确认，可执行、跳过或撤销；支持长期记忆、计划任务、指令技能与 MCP 外部工具。
- **按需 AI**：纯净模式完全离线；智能模式才启用 AI，可接 DeepSeek、Ollama、LM Studio 等兼容接口，所选内容才会发送给你配置的服务。

## 一些细节

- Windows 10 / 11 x64 桌面应用，界面跑在 WebView2 里，开发时用 Node.js 和 PowerShell 构建。
- 索引、笔记和历史存在本地 SQLite；收录不搬动原件，移除记录也不会删除原文件。
- 数据默认保存在程序目录的 `data/` 文件夹；更新时替换程序文件即可保留资料库。
